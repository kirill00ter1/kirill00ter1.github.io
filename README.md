# Империя Вкуса — сайт кафе

Одностраничный сайт фастфуд-кафе «Империя Вкуса» (Кизляр, ул. Победы, 91/1).

## Как открыть

Просто откройте `index.html` двойным кликом — сайт работает без сборки и сервера.

## Структура

```
index.html          — семантическая разметка, меню, контакты, schema.org
assets/styles.css   — стили, анимации и адаптивность
assets/script.js    — бургер-меню, анимации, подсветка категорий
favicon.svg         — иконка сайта
robots.txt          — правила для поисковых роботов
```

## Что на сайте

- Меню с ценами: пицца (25), роллы (21), бургеры (5), фастфуд (5), твистер.
- Хиты продаж: чизбургер 360 ₽, твистер 260 ₽.
- Телефон для связи: +7 (915) 300-30-07.
- График доставки: ежедневно 10:00–03:00, бронь не требуется.
- Ссылки на карту и Instagram.

## Особенности

- Палитра: тёплый тёмный фон, коралловый акцент, кремовый текст — комфортно для глаз.
- Шрифты: Oswald для заголовков, Manrope для текста (кириллица).
- Мобильное бургер-меню, плавные появления блоков, hover-эффекты карточек.
- Адаптивность: 3 колонки → 2 → 1, отдельная мобильная панель звонка.
- Учитывается `prefers-reduced-motion` — анимации отключаются по настройке системы.

## Публикация

Подойдёт любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.
Нужно загрузить `index.html`, `robots.txt`, `favicon.svg` и папку `assets` в корень сайта.

## Правки

- Меню и цены — в `index.html` (блоки `menu-group`).
- Цвета, тени и шрифты — в `:root` в `assets/styles.css`.
- Поведение меню и анимаций — в `assets/script.js`.
