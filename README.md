# Империя Вкуса — сайт кафе

Одностраничный сайт фастфуд-кафе «Империя Вкуса» (Кизляр, ул. Победы, 91/1).

## Как открыть

Просто откройте `index.html` двойным кликом — сайт работает без сборки и сервера.

## Структура

```
index.html          — разметка, меню, контакты, микроразметка schema.org
assets/styles.css   — оформление и адаптивность
assets/script.js    — анимации появления, подсветка категорий меню
favicon.svg         — иконка сайта
```

## Что на сайте

- Меню с ценами: пицца (25), роллы (21), бургеры (5), фастфуд (5), твистер.
- Хиты продаж: чизбургер 360 ₽, твистер 260 ₽.
- Телефон для связи: +7 (915) 300-30-07.
- График доставки: ежедневно 10:00–03:00, бронь не требуется.
- Ссылки на карту и Instagram.

## Публикация

Подойдёт любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.
Нужно загрузить `index.html`, папку `assets` и `favicon.svg` в корень сайта.

## Правки

Меню и цены — прямо в `index.html` (блоки `menu-group`). Цвета и шрифты — в `:root` в `assets/styles.css`.
